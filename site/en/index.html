Every game on the shelf gets its cover.

Coverly Shelf is a browser extension that puts the box art in a 3D case and a screenshot gallery on every 3DS title page on hShop. It only changes how the page looks: everything else stays the same.

Download the extension How to install it

Free and open source (AGPL-3.0). For Chrome, Edge and Brave; a Firefox version will follow.

What it adds to every title page

hShop title pages list the name, the product code and a description, but no pictures. Coverly Shelf uses that code to find the game’s cover and screenshots and places them next to the text.

The cover, in its box

The cover art appears mounted on a 3D box, next to the game’s name. It works for digital-only releases too.

Full-size screenshots

A gallery of screenshots and the title screen. They open full size and you can move through them with the keyboard.

←→Esc

At home in light and dark

It follows the page’s colours and type, in light mode and dark mode, so it looks like part of it.

It only changes how it looks

The extension leaves everything the page does alone. Here is what it can and cannot do.

  • It never touches downloads

    It only adds pictures. It does not change links, buttons or anything you download.

  • If something fails, the page is untouched

    No cover found, or the image sources are unreachable: it adds nothing and the page looks as it always did.

  • Only the permissions it needs

    Remembering in your browser which images it found, so it does not ask again, and reading images from two sites. Nothing else.

  • No tracking, no account

    No analytics, no sign-up, no server of its own. What you browse stays in your browser.

Installing takes a minute

Until it is on the Chrome Web Store, you install it by hand from the GitHub releases.

  1. Download the latest zip

    From the project’s releases page on GitHub.

    Open the latest release

  2. Unzip it into a folder you will keep

    The browser loads the extension from that folder: if you delete or move it, the extension stops working.

  3. Turn on Developer mode

    Open chrome://extensions (edge://extensions in Edge, brave://extensions in Brave) and switch on Developer mode.

  4. Load the folder

    Click Load unpacked and pick the folder, or drag the folder straight onto the extensions page.

  5. Open a title page on hShop

    The cover and screenshots appear on their own, with nothing to set up.

To update

Download the new zip, replace the folder’s contents and click Coverly Shelf’s reload button on the extensions page.

Questions

Why is it not on the Chrome Web Store?

It has not been submitted yet. Until then you install it by hand from GitHub, built from the same code you can read in the repository. When it is published, this page will say so.

Which sites does it work on?

On hShop title pages (hshop.erista.me/t/…). On every other site it does nothing. Coverly Shelf is an independent project, not affiliated with hShop or Nintendo.

Does it change anything about downloads?

No. The extension only adds pictures next to the page’s text. It does not read or change links, buttons or files.

Does it send data anywhere?

No. It only requests images from art.gametdb.com and thumbnails.libretro.com, and remembers in your browser’s storage what it found for each game. There are no analytics and no account.

What if a game has no cover?

It tries other regions and sources; if it finds nothing, it adds nothing and the page stays as it was.

Is there a Firefox version?

It is planned. Once there is a tested build, it will appear in the GitHub releases and on this page.

Is it free?

Yes. It costs nothing, needs no account and its code is AGPL-3.0.

Where the pictures come from

GameTDB

Covers come from GameTDB, a community-maintained game database. The images belong to their owners.

Libretro

Screenshots and title screens come from libretro-thumbnails, the Libretro project’s thumbnail archive.

Part of the Coverly ROMs family

Coverly ROMs does the same for the ROMs on your SD card: it finds the missing covers and adds them.
